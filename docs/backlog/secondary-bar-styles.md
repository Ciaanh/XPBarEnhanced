## Summary

Create new visual styles for the reputation/companion secondary bar beyond the current "flat" style. Investigation is underway to determine which styles are viable, how they integrate with the existing primary style system, and what the delivery plan looks like.

## Recommended Scope (pending approval)

Per [the investigation](../analysis/secondary-bar-styles-investigation.md):

- **Classic** style: Blizzard atlas textures, matches classic primary bar appearance
- **Minimal** style: thin line bar, works alongside any primary style
- Style selection via a new `secondaryBarStyle` dropdown in options

Out of scope: circular, minimap ring, terminal, vertical, or auto-matching secondary styles.
