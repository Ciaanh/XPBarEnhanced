# Searching BlizzardInterfaceResources (KethoDoc)

Machine-extracted reference data from the WoW client (build 66562, WoW 12.0.1). Generated by the KethoDoc addon. All files are pure Lua data tables.

## Location

```
${REFS_ROOT}/BlizzardInterfaceResources/Resources/
```

## File Reference

### GlobalAPI.lua (~6,627 lines)
**Content**: Flat list of every global C API function name.
**Format**: `local GlobalAPI = { "AbandonSkill", "AcceptQuest", ... }`
**Use for**: Verifying if an API function exists.
```
Grep "FunctionName" in ${REFS_ROOT}/BlizzardInterfaceResources/Resources/GlobalAPI.lua
```

### Events.lua (~2,136 lines)
**Content**: All game events organized by system/namespace.
**Format**: `local Events = { AchievementInfo = { "ACHIEVEMENT_EARNED", ... }, ... }`
**Use for**: Verifying event names, finding events by system.
```
Grep "EVENT_NAME" in ${REFS_ROOT}/BlizzardInterfaceResources/Resources/Events.lua
```

### WidgetAPI.lua (~1,479 lines)
**Content**: Widget types with inheritance, methods, and script handlers.
**Format**: Keyed by type (Frame, Button, etc.) with `inherits`, `methods`, `handlers` arrays.
**Use for**: Checking widget method existence, understanding inheritance.
```
Grep "MethodName" in ${REFS_ROOT}/BlizzardInterfaceResources/Resources/WidgetAPI.lua
```

### CVars.lua (~1,741 lines)
**Content**: Console variables with default, category, scope flags, help text.
**Format**: `local CVars = { var = { ["cvarName"] = {"default", cat, acct, char, secure, "help"} } }`
**Use for**: Verifying CVar names, checking defaults and descriptions.
```
Grep "cvarName" in ${REFS_ROOT}/BlizzardInterfaceResources/Resources/CVars.lua
```

### LuaEnum.lua (~9,014 lines)
**Content**: All Lua-exposed enumerations with numeric values.
**Format**: `Enum = { EnumGroup = { ConstantName = 0, ... }, ... }`
**Use for**: Verifying enum names and their values.
```
Grep "EnumName" in ${REFS_ROOT}/BlizzardInterfaceResources/Resources/LuaEnum.lua
```

### AtlasInfo.lua (~21,129 lines)
**Content**: Atlas texture metadata (name → coordinates/dimensions).
**Format**: Keyed by FileDataID, maps atlas names to `{w, h, l, r, t, b, tilesH, tilesV}`.
**Use for**: Finding atlas textures by name for UI elements.
```
Grep "atlas-name" in ${REFS_ROOT}/BlizzardInterfaceResources/Resources/AtlasInfo.lua
```

### FrameXML.lua (~6,221 lines)
**Content**: All global Lua functions defined in Blizzard's FrameXML.
**Format**: `local FrameXML = { "FuncName", "Module.FuncName", ... }`
**Use for**: Verifying FrameXML utility function existence (vs C API in GlobalAPI.lua).
```
Grep "FunctionName" in ${REFS_ROOT}/BlizzardInterfaceResources/Resources/FrameXML.lua
```

### Templates.lua (~3,690 lines)
**Content**: XML-defined UI templates with type, mixin, and inheritance.
**Format**: `local Templates = { ["TemplateName"] = {type="Frame", mixin="MixinName", inherits="ParentTemplate"} }`
**Use for**: Finding available templates, checking template types and inheritance.
```
Grep "TemplateName" in ${REFS_ROOT}/BlizzardInterfaceResources/Resources/Templates.lua
```

### Mixins.lua (~3,045 lines)
**Content**: Flat list of all mixin class names.
**Format**: `local Mixins = { "MixinName", ... }`
**Use for**: Verifying Blizzard mixin existence.
```
Grep "MixinName" in ${REFS_ROOT}/BlizzardInterfaceResources/Resources/Mixins.lua
```

### Frames.lua (~544 lines)
**Content**: Flat list of all named global frame objects.
**Format**: `local Frames = { "FrameName", ... }`
**Use for**: Finding available global frames.
```
Grep "FrameName" in ${REFS_ROOT}/BlizzardInterfaceResources/Resources/Frames.lua
```

### ScriptObjectAPI.lua (~171 lines)
**Content**: Methods for non-widget script objects.
**Format**: `local ScriptObjectAPI = { ObjectName = { "Method1", ... }, ... }`
**Use for**: Checking methods on special API objects.

### GlobalStrings/ (11 locale files, ~23,840 lines each)
**Content**: All localized UI strings.
**Format**: `_G["STRING_KEY"] = "Localized text";`
**Locales**: deDE, enUS, esES, esMX, frFR, itIT, koKR, ptBR, ruRU, zhCN, zhTW
**Use for**: Finding localization string keys.
```
Grep "STRING_KEY" in ${REFS_ROOT}/BlizzardInterfaceResources/Resources/GlobalStrings/enUS.lua
```

## Important Notes
- These files list **names and structure** but generally not function signatures or parameter types
- For detailed signatures, consult the domain-specific API skills (via `wow-api-index`)
- For parameter details, search `BlizzardInterfaceCode` for usage examples
- For full documentation, check https://warcraft.wiki.gg/wiki/API_<FunctionName>
